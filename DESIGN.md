# DESIGN.md — ALLUR Digital Twin

Мини-дизайн-система интерфейса. Источник значений — `frontend/css/styles.css`; этот файл фиксирует правила, по которым добавляются новые экраны. Целевой экран показа — проектор 1280×720 (зум браузера не больше 125%).

## Цвет

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#101114` | фон приложения |
| `--panel` | `#191b20` | панели |
| `--panel2` | `#202228` | вложенные блоки, полоса тура |
| `--border` | `#2c2e35` | все разделители, 1px |
| `--text` | `#f0f1f3` | основной текст; фон основной кнопки |
| `--muted` | `#a3a6af` | вторичный текст (7,8:1 на `--bg`) |
| `--dim` | `#8a8e99` | подписи, единицы (5,8:1 на `--bg`) |
| `--red` | `#ff3b30` | только логотип ALLUR |
| `--bad` | `#ff6b62` | значения за порогом, тег «нарушение» |
| `--yellow` | `#f1bb55` | риск, «Проверить первым» |
| `--green` | `#50d49a` | «в норме» |
| `--blue` | `#8ca9de` | слой «Симуляция»: живые счётчики, подпись «модель» |

### Правило красного

Красный означает нарушение норматива кейса (OEE < 85%, брак > 2%, простой > 60 мин/сутки, темп ниже плана 5 500) — и ничего больше. Основные кнопки белые (`--text`, текст `#111`), метки шагов и источника серые, активная точка тура белая. Цветные полоски слева у карточек не используются.

### Факт против модели

Данные кейса — `--text`. Всё, что считает симулятор, — `--blue` с подписью «модель». На одном экране факт и модель не должны выглядеть одинаково.

## Типографика

Inter Variable (`frontend/fonts/Inter-Variable.woff2`). Цифры всегда табличные: `font-feature-settings: "tnum" 1`.

| Размер | Где |
|---|---|
| 13 | метки и eyebrow (uppercase, letter-spacing .12em) |
| 15 | пояснения |
| 17 | lead, строки таблиц |
| 19 | заголовок находки |
| 24 | заголовок модалки |
| 38 | заголовок экрана |
| 40–46 | ключевые числа и вердикт |

Минимум 13 px на новых экранах. Существующая схема завода (SVG) пока использует 7–9 px — известное ограничение, см. дизайн-план.

## Форма

- Скругления: 4 (теги), 8 (кнопки, поля), 12 (модалка, полоса тура). Других значений нет.
- Разделители 1px `--border`; тени не используются для иерархии.

## Компоненты

| Компонент | Где | Правило |
|---|---|---|
| Строка находки | шаг 1 тура, панель руководителя | колонка числа 170px с единицами → тег (`нарушение` / `риск` / `гипотеза` / `вопрос`) → заголовок → одна строка пояснения |
| Колонка участка | итог модалки, карточка на схеме | OEE крупно, A·P·Q строкой, брак; разделители вертикальные, без фона-карточки |
| Метка источника | шапка модалки | «Файл 02.10» / «02.10 + правки» / «Продиктовано»; серая |
| Плашка «Проверить первым» | итог модалки | жёлтая рамка `#5e4a23`, фон `rgba(241,187,85,.08)` |
| `detail-panel` | боковая панель | role=dialog, Esc закрывает, стрелки листают |
| `#presentation` | полоса тура | белая кнопка «Далее», белая активная точка |

## Доступность

- Модалки: ловушка фокуса, видимая рамка фокуса 2px `--text`, результат через `aria-live="polite"`, возврат фокуса на кнопку-источник.
- Клавиши: `S` — ввести смену (не в полях ввода), Esc — закрыть, стрелки/PageDown — тур (не в полях ввода).
